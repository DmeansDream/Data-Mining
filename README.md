# Data-Mining

# Root Folder
Root folder contains a Jupiter notebook as well as a dataset for classification task that involves dividing cars into classes based on their fuel economy, while using their other characterstics for evaluation.

# 2Lab
This folder contains a Jupiter notebook that focuses on solving association and clusterization tasks using dataset for a popualar online game distributiong platform - Steam. Using this dataset, the project tries to find new association rules to predict project's success using appropriate tags for a game. The clusterization part of the notebook tries to divide whole Steam library into game clusters, and interpret resulting clusterization using different algorithms.
